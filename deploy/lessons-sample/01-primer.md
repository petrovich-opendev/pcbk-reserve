# Урок 1. Карточка тега

Это учебный образец пакета уроков (Д15а) — весь текст, тег и картинка ниже вымышленные, только для
разработки и тестов стенда. Настоящих тегов ПЦБК здесь нет.

У каждого тега есть короткое имя, например **20FAKE_001_PV** (вымышленный пример — давление на учебном
стенде), и текущее значение, которое можно спросить у агента.
