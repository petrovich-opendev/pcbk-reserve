# Резервный контур обучения ПЦБК без Dify

Отдельный продукт для технологов ПЦБК, не привязанный к Dify. Студент входит
в веб своим логином, в чате заводит агентов по своему узлу, агенты берут данные
из БДРВ через общую службу данных. Мнемосхемы в духе PI Vision показывают ход
техпроцесса и события агентов. Движок агентов — OpenCode, модель — через
OpenRouter.

## Состояние

**Постановка готова — 29.09.2026.** Владелец ответил на 16 вопросов, критерии
успеха и неуспеха приняты, включая критерии по мнемосхемам.

Порядок дальше (по решению владельца):

1. подбор навыков и брейншторм;
2. план дневными слайсами — первым чат, агент и число из БДРВ, мнемосхемы
   следом;
3. только потом реализация.

Ни плана, ни кода пока нет.

## Связь с `pcbk-ai-lab`

Dify-стенд, учебный курс и плагин доступа к БДРВ `pcbk_bdrv` — в проекте
`pcbk-ai-lab` (на GitHub — `petrovich-opendev/pcbk-ai-lab`; плагин и курс пока
в невлитой ветке). Что из них переиспользуется здесь, разобрано в разделе 9
постановки. Решение переносится в план после брейншторма.

## Правила репозитория

* **Производственные данные заказчика не коммитятся**: реестр и значения тегов
  БДРВ, описания процесса и узлов участка, выгрузки историана, материалы курса.
  Они живут на стенде и у преподавателя.
* **Секреты — никогда в git.** Пароль БДРВ, ключ OpenRouter и учётные записи
  передаются только через env-файлы на сервере.
* Личные учётные записи и имена сотрудников заказчика не пишутся.
