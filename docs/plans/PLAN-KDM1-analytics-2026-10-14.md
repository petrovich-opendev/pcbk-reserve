## Global Constraints

- 19 файлов `PROTECTED_DATA_BASELINE.json` (весь `core/pcbk_core/data/` + `gateway/calc_api.py`) и разрешённый список
  тегов не меняются; база хешей пересчитана от main 042f1b1 (Д15б поменял 3 файла только докстрингом «…10→…11»).
- `student` — технолог; идентичность и место — только из сессии (`pcbk_core.places`: `PLACES`, `CALLER_RE`), не из
  тела запроса.
- В git — ни одного имени тега ПЦБК (ворота `git diff --cached | grep -nE '\b[0-9]{2}[A-Z]{2,4}[0-9]{2}'` — пусто):
  тесты — на синтетическом корпусе `20FAKE_*`; настоящий корпус — только на сервере (`ANALYTICS_CORPUS_DIR`, как
  `LESSONS_DIR`) и в локальных тестах, которые пропускаются без переменной `KDM1_PACKAGE_DIR`.
- Сырые ответы модели не выводятся никогда; модель возвращает только ID по `contracts/llm-selection.schema.json`.
- В LLM до решения владельца уходит только публичный контекст (политика передачи — настройка, умолчание «public»).
- LLM — только через существующий LlmRole (учёт, доли, запасная модель, отмена); `llm/api.py` не меняется без
  доказанной необходимости.
- Неисправный корпус или аналитическая база не ломают вход, чат, калькуляторы, уроки.
- Тесты — важные и критичные (5 фокусов проверки плана + ключевые сценарии), не все 90 поштучно.
- Тексты/комментарии по-русски; новых зависимостей нет.
