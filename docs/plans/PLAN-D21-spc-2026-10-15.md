## Task 1: модуль расчёта `core/pcbk_core/spc.py` (вне защищённых файлов)

Чистые функции без ввода-вывода, только stdlib (`statistics`, `math`). Тест — `core/tests/test_spc.py`.

- Константы подгрупп n = 2…10 (ASTM/AIAG): A2 = 1.880, 1.023, 0.729, 0.577, 0.483, 0.419, 0.373, 0.337, 0.308;
  D3 = 0, 0, 0, 0, 0, 0.076, 0.136, 0.184, 0.223; D4 = 3.267, 2.574, 2.282, 2.114, 2.004, 1.924, 1.864, 1.816, 1.777;
  d2 = 1.128, 1.693, 2.059, 2.326, 2.534, 2.704, 2.847, 2.970, 3.078.
- `individuals(values) -> dict` (карта I-MR): CL = среднее; MR_i = |x_i − x_{i−1}|; MR̄; σ̂ = MR̄/1.128;
  UCL/LCL = CL ± 2.66·MR̄; карта размахов: CL_MR = MR̄, UCL_MR = 3.267·MR̄, LCL_MR = 0.
- `xbar_r(values, n) -> dict` (карта X̄-R): подгруппы подряд по n (хвост < n отбрасывается, число отброшенных — в
  ответе); X̿, R̄; UCL/LCL = X̿ ± A2·R̄; R: UCL = D4·R̄, LCL = D3·R̄; σ̂ = R̄/d2.
- `rules(points, cl, sigma) -> list[dict]` — 8 правил Nelson по точкам карты (индивидуальные значения или средние
  подгрупп), σ — σ точки карты (для X̄ — σ̂/√n): 1 — точка за 3σ; 2 — 9 подряд по одну сторону CL; 3 — 6 подряд
  монотонно растут или падают; 4 — 14 подряд попеременно вверх-вниз; 5 — 2 из 3 подряд за 2σ по одну сторону;
  6 — 4 из 5 подряд за 1σ по одну сторону; 7 — 15 подряд в пределах 1σ; 8 — 8 подряд вне 1σ по обе стороны.
  Нарушение: `{"rule": N, "name_ru": "...", "index": i, "zone": "A|B|C|вне"}` — индекс точки, на которой правило
  сработало. Названия по-русски (например, «точка за контрольной границей (3σ)», «9 точек подряд по одну сторону
  центральной линии», «6 точек подряд растут/падают»).
- `capability(values, sigma_within, lsl=None, usl=None) -> dict | None`: σ_общ — выборочное СКО (n−1);
  Cp = (USL−LSL)/(6σ_внутр), Cpk = min(USL−μ, μ−LSL)/(3σ_внутр); Pp, Ppk — с σ_общ; одна граница — только
  Cpk/Ppk по ней (Cp/Pp = None). Без границ — None.
- `sparkline(points, lcl, ucl, flagged) -> list[str]`: строка 1 — точки символами «▁▂▃▄▅▆▇█» по шкале от
  min(LCL, min точек) до max(UCL, max точек); строка 2 — под точками «▲» (выше UCL), «▼» (ниже LCL), «•» (иное
  нарушение), пробел иначе. Длина строк = число точек.
- Тесты с известными ответами: ряд из учебника (вычислить вручную) — CL, MR̄, UCL/LCL I-MR; X̄-R для n = 4; каждое из
  8 правил на построенном ряду срабатывает, на ровном — нет; capability с двумя и одной границей; sparkline: длины,
  маркеры. Меньше 2 точек — `ValueError` с текстом по-русски.

## Task 2: инструмент службы `calc_spc` (защищённые `service.py`, `mcp_server.py` — только добавления)

- MCP-инструмент `calc_spc(tag, period=None, start=None, end=None, points=96, subgroup=1, lsl=None, usl=None)` → в
  местах `pcbk_calc_spc`, только чтение. Один аналоговый тег; ряд — ТЕМ ЖЕ внутренним путём, что `tag_series`
  (`_tag_series`/его SQL и ворота, без нового SQL; пределы окна и бюджета — как у `tag_series`; `points` 20…96).
  Пустые/недостоверные точки — пропускаются, число — в ответе. `subgroup` 1 (I-MR) или 2…10 (X̄-R).
- Ответ (`status: ok`): `tag`, `unit`, период и пояс (как у tag_series), `chart` («I-MR» или «X̄-R»), `n_points`,
  `skipped`, `cl`, `ucl`, `lcl`, `sigma_within`, `sigma_overall`, вторичная карта (MR или R: cl/ucl/lcl),
  `violations` (время точки, правило, название, значение, зона), `in_control` (нет нарушений), `capability` (или
  null), `sparkline` (две строки), `points` (время, значение). `notes` по-русски: контрольные границы — это не
  границы допуска и не норматив ПЦБК; границы допуска — «порог технолога, не норматив ПЦБК»; точки — значения сетки
  историана (усреднение по шагу), не сырые замеры; меньше 20 точек (или подгрупп) — границы ориентировочные.
- Описание инструмента (TOOL_DESCRIPTIONS): карта Шухарта, SPC, контрольные границы, правила, Cp/Cpk — когда звать.
- Отказы аргументов — как у tag_series; учения, частота, журнал вызова — как у остальных.
- Защита КДМ-1: пересчитать `docs/kdm1/PROTECTED_DATA_BASELINE.current.json` только для изменённых файлов; абзац
  «Д21» в `docs/kdm1/DRIFT.md` (что добавлено; список тегов и прежние инструменты не тронуты).
- Тесты: `core/tests/test_service.py`, `test_mcp.py` (по месту) — ответ на вымышленном ряду, subgroup 4, границы
