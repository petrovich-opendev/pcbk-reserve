## Global Constraints

- Мест — 11 (`01`…`11`); 12 — первый недопустимый номер во всех тестах, где раньше эталоном «вне диапазона» было 11.
- Двузначный номер места (`%02d`, `student-NN`, `pcbk-student-NN`, `pcbk-stu-NN`) — без изменений формата.
- Регулярки номера — из константы (`0[1-9]|1[01]` и т. п. строятся кодом, не пишутся руками в трёх местах).
- Пределы «изменений доли за запрос» (`shares.py` `_form`, `teacher_api.py` `changes_of`) — `len(PLACES)`.
- `LLM_TOTAL_USD` пробрасывается в core из `.env` (`compose.yaml`: `LLM_TOTAL_USD: ${LLM_TOTAL_USD:-}`; пусто —
  умолчание кода 1000); на сервере — `1100` (согласовано).
- В git — ни одного имени тега ПЦБК (ворота: `git diff --cached | grep -nE '\b[0-9]{2}[A-Z]{2,4}[0-9]{2}'` — пусто).
- Тексты, комментарии — по-русски, в стиле соседнего кода; новых пакетов нет.
- Тесты core: `cd core && uv run --python 3.12 --with-requirements requirements.lock --with pytest pytest -q -p no:cacheprovider`;
  web: `cd web && npm test`; watchdog и bench — их `pytest` по образцу соседних тестов; интеграция — только на чистом
  клоне под `flock $JOB/tmp/pcbk-integration.lock`.
- Сервер, Dify и данные — только контроллер; push — `git -c credential.helper=store push`.
