## Задание

Цель — устранить подтверждённые ревью дефекты стабильности и качества, не меняя функциональности для студентов.

#### П2. Сеть до модели

Находки CROSS-02, LLM-01, TESTS-02.

1. **CROSS-02.** В `llm/upstream.py` раздели отказы на два вида:
   - `connect` — соединение не установилось: `ConnectError`, `ConnectTimeout`;
   - `pool` — нет свободного соединения в своём пуле: `PoolTimeout`.
   До модели ни один из них не дошёл.
2. **Рекомендуемая политика для `connect`** — согласуй с владельцем до кода (решение Р5).
   - Повторять **ту же модель** быстрыми попытками с коротким сроком установления соединения. Например:
     3 попытки по 4 с в пределах общего бюджета, вместо одной попытки на 10 с и затем запасной модели через тот
     же хост.
   - Потери на пути случайны, поэтому повторная попытка независима и помогает; запасная модель при сетевом
     отказе не помогает.

4. **LLM-01.** В `Upstream._get` закрытие ответа должно доходить до конца даже при сработавшем сроке:
   `anyio.CancelScope(shield=True)` вокруг `aclose()` или вынос закрытия из блока срока. Учти уточнение
   проверяющего: ответ может быть ещё не получен.
5. **TESTS-02.** Тест с «чёрной дырой»: слушатель с полной очередью соединений (по образцу `full_backlog_url` из
