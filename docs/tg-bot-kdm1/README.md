# Бот «Подборка для КДМ-1»

Подпроект рядом со стендом: Telegram-бот раз в день присылает владельцу-технологу короткую подборку
внедрённых на других фабриках идей операционной эффективности, релевантных КДМ-1, — каждая с результатом в
цифрах, цитатой со страницы источника и ссылкой. Данных ПЦБК бот не касается: ни БДРВ, ни базы знаний, ни
разговоров студентов.

Код бота ведётся отдельным локальным git-репозиторием `tg-bot-kdm1` (пакет `kdm1digest`, удалённого адреса
нет). Здесь — его описание для владельца и разработчика; пути вида `docs/TASK.md`, `docs/specs/…`,
`docs/checks/day1.md`, `kdm1digest/*.py` в этих документах — пути внутри репозитория бота.

**Состояние на 16.10.2026:** день 1 закрыт (банк случаев, проверки без модели, публикация в файл; теги
`v0.1.0`, `v0.1.1`). В Telegram бот не запущен — ждёт слова владельца. Дни 2–3 (сборщик, кнопки, старт
пробы) — в плане.
