- Runtime `runsc` подключён; сетей Docker и маршрутов в подсетях мест
  (`${STU_NET}.1–10.x`) нет. [П]
- `.env`: `STU_NET`, `SECRETS_DIR`, `AGENTS_DIR` заданы, каталоги — под
  `/opt/pcbk-reserve`. [П]
- Память: доступно ≈ 11,6 ГиБ из 15,6; **swap есть — 4 ГиБ** (занято 9 МиБ),
  поэтому `memswap_limit` у мест обязателен. [П]
