# Д24 (выложено 16.10): график карты Шухарта в чате

Вопрос владельца 16.10 (ночь, после Д23): «встроить примитивные графики в чат для более наглядной работы с SPC — можем
успеть?»; на предложение (чат рисует карту из ответа службы, одно поле в защищённом `service.py`) — «Да, автономно
сделай все сам».

## Что сделано

- **Служба (`service.py`, защищённый файл — по решению владельца):** ответ `calc_spc` со статусом `ok` получает
  последним полем `plot` — точки карты (I или X̄), точки вторичной карты (MR — на одну меньше, R — по подгруппам),
  индексы точек с нарушениями правил, `lsl`/`usl`, время первой и последней точки; 5 значащих цифр. При `partial` —
  `null`. База защиты и `docs/kdm1/DRIFT.md` (раздел Д24).
- **Чат (`web/src/components/SpcChart.tsx`):** под строкой «Запрос к данным: карта Шухарта — готово» — SVG: карта I
  или X̄ с CL (сплошная), UCL/LCL (пунктир), LSL/USL (точечные, если допуск был), точки с нарушениями — красным; ниже
  карта MR или R; время первой и последней точки; подпись «Нарушения правил: N точек (красным)» или «Нарушений правил
  нет». Разбор ответа строгий: не тот вид, обрезанный вывод, отказ, идущий вызов — графика нет, строка вызова и вывод
  как были. Текст ответа — только текстом React; цвета — классами `chat.css` (светлая и тёмная тема), без
  style-атрибутов; без API новее Chrome 109. Подпись инструмента `pcbk_calc_spc` — «карта Шухарта».
- **Правила агентов:** Помощник (редакция 7), Конструктор (шаблон SPC агентов студентов), `AGENTS.md` п.9 — график
  чат рисует сам; мини-график и числа `plot` не повторять.
- **Уроки 16–17 на сервере** (вне git): тексты — про график под строкой вызова, снимки пересняты под student_test;
  оглавление `lessons.json` — описание урока 16. Копии — `*.pre-d24`, `img/pre-d24/`.
