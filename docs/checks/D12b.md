## `audit.py` и самопроверка

Только stdlib (Python 3). Берёт JSONL-транскрипт, вытаскивает все `Bash`- и `Read`-вызовы, сверяет
каждую Bash-команду (пробелы нормализованы) со строками кода `ADMIN.md`/`README.md` — построчно
(фенс-блоки ``` ``` и инлайн-код в прозе) и блоками целиком (многострочные команды), с местами `<…>`
и `NN`/`N` как шаблонами и подстановками `subst.md` (строки таблицы, где обе стороны — инлайн-код).
Служебные команды (`report.md`, `cat`/`ls`/`sed -n`/… только по путям `$HANDS` вне `twin/`) — отдельной
меткой. Отдельно проверяет все прочитанные пути (`Read` и пути внутри Bash-команд): нарушение — путь
вне `$HANDS` или внутри `$HANDS/twin/`.

Пойманная при самопроверке и исправленная до прогона уязвимость матчера: строка-шаблон, целиком
состоящая из мест `<…>` (например `<прошлый день>` или `<id> <sha256>`) вырождается в «что угодно»,
если её не отбрасывать — добавлен порог `MIN_LITERAL` (не меньше 4 буквенно-цифровых знаков после
снятия мест) и подсчёт путей исключает URL (`scheme://…`) целиком, не только хвост после порта.

Самопроверка — 4 поддельных JSONL в `hands/audit-selftest/` (`case1-ok`, `case2-service`,
`case3-unmatched`, `case4-violation`), прогон после правок:

| Случай | Что внутри | Итог |
|---|---|---|
| `case1-ok` | `curl -sk https://127.0.0.1:18443/status.json`, `Read` файла в `bundle/` | совпала с `README.md:50` (инлайн, после подстановки `8443→18443`); `Read` — ок; нарушений 0 |
| `case2-service` | `cat .../TASK.md`, `printf … >> report.md` | обе — «служебная»; нарушений 0 |
| `case3-unmatched` | `docker exec pcbk-core rm -rf /var/lib/pcbk-core` | «НЕ СОВПАЛА»; нарушение — путь `/var/lib/pcbk-core` вне `$HANDS` |
| `case4-violation` | `Read` файла репозитория вне `$HANDS`; `cat` файла внутри `twin/core-twin/` | оба — нарушение (вне `$HANDS`; внутри `twin/`); Bash дополнительно — «НЕ СОВПАЛА» |

Все четыре — ожидаемый результат. Ограничение инструмента (честно, не прятать): сверка текстовая, не
семантическая; если чистые руки разобьют многострочный блок инструкции на несколько отдельных вызовов
Bash или перескажут его не слово в слово, блочный матчер может не найти совпадение и дать «НЕ СОВПАЛА»
для по сути верной команды — это читает уже человек по `report.md` рядом с таблицей `audit.py`.
