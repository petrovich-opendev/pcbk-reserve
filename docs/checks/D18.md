# Д18 — основная модель Claude Opus 5.5 (15.10.2026)

Просьба владельца 15.10: «переключиться на самую продвинутую модель рассуждения … Fable 5.1 (найти в OpenRouter)».

## Что выяснено и решено

- `anthropic/claude-fable-5.1` в OpenRouter есть (точки Anthropic, Azure, Amazon Bedrock, Google; вход $10, выход $50 за
  1 млн токенов), но **ни одной точки в списке ZDR** (`GET /api/v1/endpoints/zdr`, 15.10 ~08:00 UTC). Прокси шлёт
  `zdr: true` всем моделям (`PROVIDER_FIXED`), то есть вызов Fable был бы отклонён, а снятие ZDR пустило бы данные ПЦБК
  (телеметрия БДРВ, корпус КДМ-1, разговоры студентов) к провайдеру без гарантии нулевого хранения.
- Решение владельца 15.10 (вопрос с вариантами): **Opus 5.5 с ZDR, на всех местах и в аналитике**.
- Точка `google-vertex/global` — без вариантов региона, в списке ZDR, цены: вход $4, выход $20, запись кэша $5 за
  1 млн (Bedrock и региональные Vertex — на 10 % дороже); effort high; `cache_control` верхнего уровня, как у Sonnet 5.5.
- Места — через провайдер `pcbk-or` (`@openrouter/ai-sdk-provider`): он возвращает `reasoning_details` с подписями,
  которые Claude требует обратно в шагах с инструментами (Д4б-R20). Модель добавлена в оба провайдера образа места.
- Запасная при отказе Opus — DeepSeek (`LLM_FALLBACK`, один повтор за вызов). DeepSeek остаётся в `LLM_MODELS`.

## Код (ветка d18/opus)

- `core/pcbk_core/llm/models.py` — восьмая модель белого списка; тесты таблицы и списка; строка запуска «моделей 8».

- `compose.yaml` — `core:d18`, `student:d18`; `deploy/README.md` — «Модели по ролям», значения `.env` и мест, откат.

## Известные ограничения

- **Разговор, начатый до переключения, остаётся на DeepSeek**: шлюз не передаёт модель (только текст и агента), а
  OpenCode берёт модель последнего сообщения разговора. Новый разговор — Opus. Чтобы перевести и старые, нужна правка
  шлюза (подставлять модель сервера в каждый запрос) — по решению владельца.
- Цена: Opus в 20–33 раза дороже DeepSeek за токен; доли мест прежние ($100 на студента, всего $1100).
- Следы проверки: агент «Проба Opus» и два разговора аналитики у student_test.
